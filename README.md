# ARXA Studio — Arxitektura Portfolyo

**Soft UI (Neo-UI)** uslubidagi zamonaviy arxitektura portfolyo sayti.

## Navi raqam?

- 🎨 **Asosiy ranglar:** och ko'k (`#e9f1fb`) va to'q ko'k (`#123a78`)
- ️ Barcha arxitektura rasmlari AI yordamida yaratilgan
- ✨ Soft shadows, yumaloq burchaklar, yumshoq animatsiyalar

## Sahifa bo'limlari

1. Hero — asosiy shior va statistika
2. Xizmatlar — 6 ta xizmat kartasi
3. Biz haqida — studio haqida ma'lumot
4. Loyihalar — filtrli portfolyo (Uylar / Binolar / Ichki dizayn / Jamoat)
5. Statistika — animatsion hisoblagichlar (to'q ko'k panel)
6. Mijozlar fikri
7. Aloqa — forma va kontakt ma'lumotlari

## Texnologiyalar

- Toza HTML5 + CSS3 (Custom Properties) + Vanilla JavaScript
- Frameworklar ishlatilmagan
- To'liq responsiv (mobil, planshet, desktop)
- IntersectionObserver bilan reveal-animatsiyalar va hisoblagichlar

## Ishga tushirish

```bash
# Ixtiyoriy: Python HTTP server orqali
python3 -m http.server 8000

# yoki
npx serve .
```

Brauzerda `http://localhost:8000` oching.

## Tuzilma

```
├── index.html          # Asosiy sahifa
├── css/styles.css      # Soft UI dizayn tizimi
├── js/main.js          # Interaktiv funksiyalar
└── images/             # AI-generatsiyalangan arxitektura rasmlari
```
